# Design-Space Simulation

Generated by `python -m sim.run` from the analytical model in `sim/`. The simulator screens hypothetical architectures; it does not measure silicon, and it does not turn a model result into an evidence claim.

> **Scope:** these are assumptions at a shared reference node. The next gate is iso-accuracy validation, then RTL or FPGA prototyping.

## Model

| Assumption | Value |
|---|---|
| Reference node | 5 nm |
| Reference clock | 1.0 GHz |
| Cost model | $0.35/mm² + $8.00 package |
| Compute time | effective ops / (peak ops × workload utilization) |
| Memory time | bytes moved / peak bandwidth |
| Interconnect time | communication bytes / peak interconnect bandwidth |
| Latency | max(compute, memory, interconnect) × mapping overhead + fixed latency + dependency |
| Energy | ops × energy/op + bytes × energy/byte + communication × energy/comm-byte |

The utilization and overhead multipliers encode workload-to-structure fit. They are the most important sensitivity knobs, not measured constants.

## Design space

| Axis | Values |
|---|---|
| `execution_model` | SIMD, SIMT, spatial, event-driven, stochastic, near-memory, photonic |
| `memory_hierarchy` | cache+HBM, HBM+SRAM, SRAM-only, compute-in-memory, optical |
| `dataflow` | control, weight-stationary, output-stationary, event, sampling |
| `interconnect` | mesh, NoC, all-to-all, optical |
| `numeric_format` | int8, fp8, mixed, analog |
| `programming_model` | threads, graph, dataflow, event-graph, probabilistic |

Cartesian space: **14,000** combinations. Evaluated in this sprint: **13** candidates × **3** workloads = **39** experiments.

## Reading the result

- The frontier is workload-specific. A design that wins on one workload is not a universal replacement for a CPU, GPU, or NPU.
- A Pareto marker means no other evaluated candidate is better on latency and energy at the same time. Cost and area are reported separately and are not part of the frontier test. It does not mean the design is buildable.
- The baseline rows are deliberately conservative placeholders. Replace them with measured baselines before making procurement or investment claims.
- Accuracy is a gate, not a simulated metric. A candidate must first match the baseline's accuracy on the target workload.

## Limitations

- Analytical roofline, not cycle-accurate simulation.
- No SRAM capacity, NoC contention, yield, packaging, thermal, or compiler effects are modelled.
- No accuracy or numerical-stability measurement.
- The candidate list is a hand-pruned sample of a much larger design space.
- All numbers are assumptions at one reference node; they are not predictions.
